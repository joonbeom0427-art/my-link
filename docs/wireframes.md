# 📐 마이링크 (My Link) - 와이어프레임 구조도 (Wireframes)

본 문서는 **“마이링크 (My Link)”** 서비스의 핵심 화면 설계와 컴포넌트 배치를 나타내는 와이어프레임 구조도 문서입니다. **Shadcn/ui 및 Tailwind CSS**의 디자인 미학을 녹여내어 모던하고 직관적인 레이아웃을 정의합니다.

---

## 1. 관리 대시보드 (Admin Dashboard) - 데스크톱 뷰

관리 대시보드는 좌측의 **편집 제어판(Editor Control Panel)**과 우측의 **실시간 모바일 프리뷰(Live Mobile Preview)** 영역으로 나뉜 2열(Split-Pane) 레이아웃을 채택합니다.

### 1.1 편집 제어판 컴포넌트 사양 (Shadcn/ui 매핑)
1. **상단 네비게이션 바 (Navbar)**:
   * **Shadcn Component**: `NavigationMenu`, `Button` (주소 복사용), `Avatar` (사용자 프로필), `DropdownMenu` (로그아웃 버튼).
   * **다크 모드 스위치**: `Switch` 컴포넌트를 사용하여 시스템 다크 모드를 원터치로 전환합니다.
2. **프로필 설정 영역 (Profile Section Card)**:
   * **Shadcn Component**: `Card`, `Input` (닉네임), `Textarea` (한 줄 소개), `Badge` (기술 스택 및 도메인 태그).
3. **링크 관리 목록 영역 (Link CRUD Section)**:
   * **Shadcn Component**: `Card`, `Button` (새 링크 추가용), `Switch` (노출 ON/OFF 토글).
   * **새 링크 추가 다이얼로그 (Dialog)**: 추가 버튼 클릭 시 화면 중앙에 `Dialog`가 오버레이됩니다. 제목, URL 입력창이 들어있으며, URL 입력 시 실시간으로 파비콘 로고 미리보기가 제공됩니다.
   * **드래그 핸들 ([=])**: 정렬 순서를 바꿀 수 있는 Drag Handle 아이콘 컴포넌트가 결합됩니다.
4. **디자인 시스템 영역 (Design Customizer)**:
   * **Shadcn Component**: `Select` (테마 프리셋 선택), `RadioGroup` (둥글기 반경 설정).

## 2. 공개 랜딩 페이지 (Public Landing Page) - 모바일 뷰 (모바일-퍼스트 반응형)

실제 방문자가 고유 주소(`mylink.at/{username}`)로 진입했을 때 모바일 브라우저 화면 전체에 가득 차게 구현되는 최적화 뷰입니다.

```
       +------------------------------------+  <-- 모바일 상단 브라우저 바 영역
       |                                    |
       |             ( Avatar )             |  <-- 1. 원형 프로필 이미지 (Google 프로필 연동)
       |                                    |
       |            Minwoo Dev              |  <-- 2. 프로필 닉네임
       |      안녕하세요, 개발자입니다.     |  <-- 3. 한 줄 소개 글 (Bio)
       |                                    |
       |    [ React ] [ Next.js ] [ Node ]   |  <-- 4. 기술 태그 배지 리스트 (Shadcn Badge)
       |                                    |
       |  +------------------------------+  |
       |  | (🌐)  기술 블로그            |  |  <-- 5. 파비콘이 내장된 링크 버튼 1
       |  +------------------------------+  |     (Shadcn Button - Outline or Glass)

       |  +------------------------------+  |
       |                                    |
       |  +------------------------------+  |
       |  | [🐙]  GitHub Contribution    |  |  <-- 7. 리치 미디어 블록: GitHub 잔디
       |  |                              |  |     (Shadcn Card - Dark/Light 테마 매핑)
       |  |   ■■■▨▨■■■                  |  |
       |  |   ■■▨■■▨▨■                  |  |
       |  +------------------------------+  |
       |                                    |
       |             [ SNS ]                |  <-- 8. 하단 소셜 바로가기 아이콘 목록
       |      (Git)  (LinkedIn)  (X)        |     (Lucide Icons 기반 투명 원형 버튼)
       |                                    |
       |       Powered by My Link           |  <-- 9. 하단 브랜딩 푸터 영역
```

### 2.1 공개 페이지 레이아웃 세부 명세
* **전체 컨테이너**: Tailwind `max-w-md mx-auto w-full px-4 py-8`을 적용하여 데스크톱 접속 시에도 좌우가 깔끔히 고정되는 모바일 세로 뷰를 유지합니다.
* **프로필 영역**:
  * **Avatar**: `w-24 h-24 rounded-full border-2 border-primary shadow-sm` 형태의 원형 마스크 이미지.
  * **배지 행**: `flex flex-wrap justify-center gap-1.5`로 줄 바꿈 대응 및 자간을 부드럽게 조정합니다.
* **링크 버튼들**:
  * `w-full h-12 flex items-center justify-between px-4 transition-transform active:scale-95`를 지향합니다.
  * **버튼 내부 정렬**:
    * **좌측**: URL 분석으로 획득된 **16px 크기의 파비콘 이미지** 배치.
    * **중앙**: 가독성이 높은 중간 굵기(`font-medium`)의 타이틀 텍스트.
    * **우측**: 외부 링크 새창 이동을 의미하는 얇은 화살표 아이콘 (`ArrowUpRight`).
* **GitHub 잔디 위젯**:
  * Shadcn `Card` 내부에 반응형 `svg` 혹은 스케일링이 가능한 래퍼를 씌워 화면 폭을 100% 채울 수 있도록 구현합니다. 다크 모드에 반응하여 초록색 명암 단계 색상이 알맞게 매핑됩니다.
* **소셜 아이콘 풋노트**:
  * 모바일 터치 피드백을 위해 클릭 영역 `min-w-[44px] min-h-[44px]`을 확보하고, 반투명 효과(`opacity-80 hover:opacity-100`)를 적용합니다.
