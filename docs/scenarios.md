# 👥 마이링크 (My Link) - 사용자 시나리오 (User Scenarios)

본 문서는 **“마이링크 (My Link)”** 서비스의 핵심 타겟층인 **개발자(Developer)**와 **크리에이터(Creator)**, 그리고 **방문자(Visitor)**의 실제 서비스 사용 흐름을 구체화한 사용자 시나리오 문서입니다. [PRD](file:///c:/Users/joonb/OneDrive/문서/my-link/docs/prd.md)의 기능 ID와 연계하여 설계되었습니다.

## 1. 페르소나 정의 (Persona Definitions)

### 페르소나 A: 테크니컬 유저 (개발자 "민우")
* **직업**: 3년 차 프론트엔드 개발자
* **목표**: 자신의 사이드 프로젝트 결과물, GitHub 잔디, Velog 블로그 글, X(구 트위터) 계정 등을 깔끔하고 모던한 하나의 링크로 통합하여 이력서와 SNS 프로필에 등록하고 싶음.
* **성향**: 복잡한 꾸미기 요소나 화려한 애니메이션보다는 깔끔하고 정돈된 인터페이스, 다크 모드, 그리고 마크다운이나 코드 블록 같은 테크니컬 감성을 선호함.

### 페르소나 B: 창작자 (테크 크리에이터 "소율")
* **직업**: IT 트렌드를 다루는 유튜버 및 뉴스레터 발행인
* **목표**: 매주 발행하는 이메일 뉴스레터 구독을 유도하고, 최신 유튜브 영상을 홍보하며, 시청자들의 후원(Toss)을 편리하게 유도할 수 있는 모바일 중심 페이지가 필요함.
* **성향**: 직관적인 모바일 조작, 구독 신청 폼 연동, 그리고 트렌디하고 화사한 디자인 테마 선호.

## 2. 사용자 시나리오 (User Scenarios)

### 시나리오 1: 개발자 민우의 프로필 구축 및 공유 (F-1.1, F-1.2, F-2.1, F-3.1, F-3.3, F-4.1, F-6.1)

1. **로그인 및 아이디 선점 (F-1.1, F-2.1)**
   * 민우는 트위터에서 다른 개발자의 마이링크 프로필을 보고 서비스에 접속합니다.
   * `Google 계정으로 로그인` 버튼을 클릭하여 파이어베이스를 통해 3초 만에 인증을 마칩니다.
   * 최초 가입 온보딩 화면에서 원하는 주소 이름인 `minwoo-dev`를 입력하고 중복 검사를 거쳐 `mylink.at/minwoo-dev`라는 고유 URL을 선점합니다.

2. **프로필 및 기술 스택 배지 설정 (F-1.2)**
   * 대시보드 진입 시 구글 프로필 사진이 자동으로 연동되어 있는 것을 확인합니다.
   * 프로필명을 'Minwoo | Frontend Engineer'로 수정하고, 한 줄 소개에 '기술로 세상을 이롭게 하고 싶은 개발자입니다.'를 입력합니다.
   * 태그 입력창에 `React`, `Next.js`, `TypeScript`를 입력하여 프로필 바로 하단에 Shadcn/ui 디자인의 배지(Badge) 형태로 등록합니다.

3. **포트폴리오 및 외부 링크 등록 (F-3.1)**
   * `새 링크 추가` 버튼을 클릭합니다.
   * 제목에 `Velog 기술 블로그`를 적고 주소에 `https://velog.io/@minwoo`를 입력합니다.
   * 저장을 누르자마자, 시스템이 Velog의 파비콘을 자동으로 추출하여 버튼 왼쪽에 깔끔하게 배치해 줍니다. 
   * 추가로 자신의 포트폴리오 사이트(`https://minwoo.dev`)와 이력서 링크를 등록합니다. 각각의 파비콘이 자동으로 매칭되어 매우 깔끔한 리스트가 구성됩니다.

4. **GitHub 잔디 연동 및 다크 모드 적용 (F-4.1, F-6.1)**
   * 개발자 특화 블록인 `GitHub 잔디 위젯`을 추가하고 자신의 GitHub ID인 `minwoodev`를 입력합니다.
   * 랜딩 뷰 우측 실시간 프리뷰 영역에 자신의 1년간 기여도(잔디밭) 그래픽이 나타납니다.
   * 디자인 탭으로 이동하여 Shadcn/ui 기반의 **'Midnight Dark' (다크 모드)** 테마를 선택합니다. 전반적인 레이아웃이 쿨그레이 및 다크 톤으로 모던하게 변경됩니다.
   * 만족한 민우는 상단의 주소 복사 버튼을 눌러 자신의 GitHub Readme와 X(구 트위터) 프로필 링크에 등록합니다.

### 시나리오 2: 크리에이터 소율의 마케팅 및 후원 연동 (F-1.1, F-3.1, F-3.2, F-4.2, F-6.1, F-6.2)

1. **소셜 로그인 및 테마 설정 (F-1.1, F-4.2)**
   * 소율은 모바일 태블릿에서 마이링크에 접속하여 구글 계정으로 로그인합니다.
   * 본인의 유튜브 채널명과 매칭되는 `tech-soyul` 주소를 생성합니다.
   * 브랜딩 톤앤매너에 맞게 부드럽고 둥글둥글한 느낌을 주고 싶어, 디자인 커스텀 메뉴에서 버튼 둥글기 강도를 `Pill` (완전 둥글게)로 변경하고 화사한 파스텔톤 프리셋 테마를 선택합니다.

2. **유튜브 임베드 및 후원 블록 배치 (F-6.1, F-6.2)**
   * `새 블록 추가` 메뉴에서 `미디어 임베드`를 선택한 후, 어제 올린 자신의 최신 유튜브 영상 주소를 붙여넣습니다. 
   * 프리뷰 화면에 텍스트 버튼이 아닌, 반응형 유튜브 동영상 플레이어가 직접 렌더링되는 것을 확인합니다.
   * 채널 유지비 및 창작 지원을 유도하기 위해 `후원 블록`을 추가합니다. 토스 송금 링크(`https://toss.me/techsoyul`)를 입력하고 '소율에게 따뜻한 아메리카노 한 잔 선물하기 ☕'라는 매력적인 문구를 작성하여 눈에 띄는 Shadcn/ui 디자인의 후원 카드를 완성합니다.

3. **뉴스레터 및 링크 순서 조정 (F-3.1, F-3.2)**
   * 구독자들을 모으고 있는 스티비(Stibee) 뉴스레터 구독 링크를 맨 위로 올리기 위해, 대시보드 내의 드래그 핸들을 잡고 마우스로 끌어 올려 최상단에 배치합니다.
   * 실시간 프리뷰 화면에서도 즉시 뉴스레터 버튼이 가장 잘 보이는 맨 위쪽으로 부드럽게 이동합니다.
   * 만족스럽게 완성된 페이지 주소를 복사하여 인스타그램 프로필 링크(Link-in-bio)에 삽입합니다.

### 시나리오 3: 일반 방문자 C의 링크 페이지 접속 및 탐색 (F-2.2, F-3.1, F-6.1, F-6.2)

1. **초고속 모바일 접속 (F-2.2)**
   * 대학생 지훈이는 인스타그램을 탐색하다가 크리에이터 소율의 프로필 링크(`mylink.at/tech-soyul`)를 터치합니다.
   * 인앱 브라우저 내부에서 1초 만에 깔끔한 Shadcn/ui 파스텔 톤 테마로 디자인된 소율의 마이링크 프로필이 쾌적하게 로딩됩니다.

2. **콘텐츠 소비 및 외부 채널 이동 (F-3.1, F-6.1)**
   * 지훈이는 페이지 상단에 노출된 소개글과 기술 스택 배지들을 읽고 전문성을 느낍니다.
   * 페이지 내부에서 나가지 않고도, 임베드된 최신 유튜브 영상을 직접 재생하여 짧은 소개 팁을 시청합니다.
   * 더 많은 지식을 얻기 위해 `Velog 기술 블로그` 버튼을 터치합니다. 각 버튼 왼쪽에 선명하게 나타나 있는 Velog 파비콘 덕분에 직관적으로 어떤 사이트로 이동할지 인지하며 새 탭으로 이동합니다.

3. **크리에이터 후원 (F-6.2)**
   * 소율의 영상과 포스팅에 깊은 감명을 받은 지훈이는 다시 마이링크 페이지로 돌아옵니다.
   * 하단에 정렬된 '소율에게 따뜻한 아메리카노 한 잔 선물하기' 후원 블록을 터치하여 토스 앱으로 안전하게 이동한 뒤 5,000원을 후원합니다.
